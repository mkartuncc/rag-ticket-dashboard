How do I write a for loop in python?

**Route:** `python_book`

**Sender:** Medha Karthik <z.medhak@gmail.com>

## Answer

To write a for loop in Python, you use the following syntax:

```python
l = [1, 7, 8] 
for item in l: 
    print(item)  # This will print 1, 7, and 8
```

The `for` loop iterates through each item in the sequence (like a list, tuple, or string) and executes the block of code within the loop for each item.
